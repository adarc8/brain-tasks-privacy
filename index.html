brain tasks

brain tasks is a private, single-user tool run by Adar Cohen for his own accounts. It is not offered to the public.

Privacy policy

The app reads the owner's own Google Tasks, Gmail and Calendar data, and creates tasks in the owner's own Google Tasks list. Data is processed only on the owner's own computer, is not sold, shared with third parties, or used for advertising, and is not used to train models.

Google user data is handled in line with the Google API Services User Data Policy, including the Limited Use requirements.
